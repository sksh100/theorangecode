# 🚀 Quick Google Analytics Setup Guide

## What's Already Done ✅

- ✅ Google Analytics code is installed and configured
- ✅ All tracking events are set up
- ✅ Component is integrated into your site

## What You Need to Do (5 minutes)

### 1. Add Environment Variable in Vercel (2 min)

**Copy and paste these exact steps:**

1. Go to: https://vercel.com/dashboard
2. Click your project
3. Click **Settings** → **Environment Variables**
4. Click **Add New**
5. **Name:** `NEXT_PUBLIC_GA_MEASUREMENT_ID`
6. **Value:** `G-BE1VBMP27H`
7. Check ✅ all three: Production, Preview, Development
8. Click **Save**

### 2. Redeploy (1 min)

1. Click **Deployments** tab
2. Click **⋯** on latest deployment
3. Click **Redeploy**
4. Wait 2-3 minutes

### 3. Verify (2 min)

1. Visit: https://www.theorangecode.com
2. Go to: https://analytics.google.com → **Realtime**
3. You should see your visit appear!
