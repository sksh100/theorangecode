# Notification Sound File

## Required: Add `ding.mp3`

The admin dashboard uses a notification sound file for live updates. Please add a `ding.mp3` file to this directory (`public/ding.mp3`).

### Recommended Specifications:
- **Format**: MP3
- **Duration**: 0.5-1 second
- **File size**: ~50-200KB
- **Sample rate**: 44.1kHz
- **Channels**: Mono or Stereo

### Free Sound Resources:
- [Freesound.org](https://freesound.org) - Search for "ding" or "notification"
- [Mixkit](https://mixkit.co/free-sound-effects/notification/) - Free notification sounds
- [Zapsplat](https://www.zapsplat.com/sound-effect-categories/notification-sounds/) - Notification sound effects

### Quick Option:
You can also use a simple beep sound generated online or record a short notification tone.

Once you add `ding.mp3` to this folder, the notification sound will work automatically in the admin dashboard!
