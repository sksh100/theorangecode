# Earth Texture

Please add an Earth night texture image here.

**File name:** `earth-night.jpg`

**Recommended sources:**
- NASA Visible Earth: https://visibleearth.nasa.gov/
- Blue Marble Night Lights: https://earthobservatory.nasa.gov/features/NightLights
- Public domain Earth textures

**Recommended specifications:**
- Format: JPG or PNG
- Resolution: 2048x1024 or higher (4096x2048 ideal)
- Type: Earth night map showing city lights and coastlines

Once you add the texture file, the 3D globe will display a realistic Earth with the GCC region visible.
